# Contributing

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities as
described in [SECURITY.md](SECURITY.md), not in public issues. [CONTEXT.md](CONTEXT.md)
defines the terms the code and docs use.

```sh
mise install
mise run hooks
```

Before opening a ready-for-review pull request, run `mise run check`.
`mise run format` fixes formatting. Describe the observable problem, the
resulting behavior, the checks you ran and anything you couldn't validate.
